LUX WEBSITE PACKAGE

В архиве только один основной index.html — никаких дублирующих index-файлов.
Все файлы лежат в корне архива, без вложенных папок.

Файлы:
- index.html — основной сайт; добавлена ссылка «Админ-панель» внизу.
- style.css — стили.
- app.js — существующий LUX AI без изменения его логики.
- admin.html — страница входа администратора.
- admin.js — проверка входа Supabase и UID в lux_admins.
- supabase-config.js — настройки Supabase.

ПЕРЕД ТЕСТОМ:
1. В supabase-config.js впиши Project URL и Publishable (anon) key.
2. Не вставляй Secret key или service_role key.
3. Проверь, что в public.lux_admins есть UID пользователя и роль owner.
4. Загрузи все 6 файлов в корень GitHub-репозитория, заменив index.html/style.css/app.js.
5. Открой /lux/admin.html.

ВАЖНО:
- Админ-панель пока проверяет авторизацию и наличие пользователя в lux_admins.
- Управление новостями, жителями и заявками ещё не реализовано.
- Форма вступления и LUX AI остаются в прежнем демонстрационном режиме.
- Старые копии вроде "index 2.html" в репозиторий загружать не нужно.
