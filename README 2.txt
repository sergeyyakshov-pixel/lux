LUX — пакет сайта для GitHub Pages

Содержимое:
- index.html, style.css, app.js — текущий сайт и локальный LUX AI без изменения логики.
- admin.html, admin.js — заготовка страницы входа администратора.
- supabase-config.js — пустые поля для публичных параметров Supabase.
- supabase-admin-policies.sql — пока не включён: политики доступа нужно согласовать с фактическими grants и RLS проекта.

Установка:
1. Распакуй архив.
2. Загрузи файлы в корень репозитория GitHub Pages, заменив старые index.html/style.css/app.js.
3. Страница админки будет доступна по адресу /lux/admin.html.
   GitHub Pages для обычного статического сайта не создаёт маршрут /admin автоматически.
4. Перед подключением админки настрой Supabase и RLS отдельно.

Важно:
- Форма вступления на главной пока демонстрационная и не отправляет заявки.
- LUX AI остаётся локальным SMART MODE.
- В админке пока нет управления новостями и жителями; это только безопасная заготовка входа.
- Не публикуй пароль, Secret key или service_role key.
